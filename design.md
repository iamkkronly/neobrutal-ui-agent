# NeoBrut UI Design Rules

**Read this file before building any UI.**

- **Neo-Brutalism is always the primary design style.** Use bold typography, high contrast, flat colors, thick dark borders, visible structure, and hard offset shadows.
- **Typography is important.** Use expressive headings with clear, readable body text and hierarchy.
- **Retro Pixel Art is optional.** Use it only as a small accent, icon, sticker, or illustration when it fits the product.
- **Claymorphism is optional.** Use it only when a friendly, tactile component genuinely needs it; never make the whole UI clay-like.
- **Glassmorphism should normally be avoided.** Use it only when a specific overlay or interaction truly needs it, while keeping Neo-Brutalism visible around it.
- Never mix all styles equally. Keep every interface clear, accessible, responsive, and Neo-Brutalist first.
