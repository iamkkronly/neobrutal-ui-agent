# Contributing

1. Keep Neo-Brutalism primary.
2. Add or update tokens before adding one-off values.
3. Document a new visual pattern in `agent/design-contract.md` or a component recipe.
4. Keep the dependency-free demo working.
5. Run `python3 scripts/validate.py` before opening a pull request.

A new supporting style must explain why it improves the user's task and why the existing Neo-Brutalist system is insufficient on its own.
