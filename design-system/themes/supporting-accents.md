# Supporting accents

The repository includes four requested style directions, but they have a strict role hierarchy:

| Style | Default role | Use when | Avoid when |
| --- | --- | --- | --- |
| Neo-Brutalism | Primary system | Always | Never remove it from the base layout |
| Typography | Hierarchy and voice | Always, with restraint | The type treatment harms readability |
| Retro Pixel Art | Small decorative accent | The product benefits from play, nostalgia, or game-like feedback | It overwhelms information architecture |
| Claymorphism | One tactile/friendly object | A physical metaphor improves understanding | It softens the whole interface |
| Glassmorphism | Context-preserving overlay | A modal, command palette, or floating inspector needs background context | It is being used as the page-wide style |

## Mixing rule

Use no more than one supporting accent as the dominant accent on a screen. The brutalist grid, borders, contrast, and hard shadows must remain visible even when an accent is present.
