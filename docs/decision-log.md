# Decision log

## 2026-09-18 — Neo-Brutalism as the base system

The requested styles are intentionally not treated as equal themes. A single primary system creates consistency for an AI agent. Neo-Brutalism owns structure, contrast, depth, and interaction. Typography is a foundational layer, while Retro Pixel Art, Claymorphism, and Glassmorphism are constrained accents.

This hierarchy prevents an agent from producing a visual mashup and gives it a deterministic choice when a prompt does not specify a style.

## 2026-09-18 — Dependency-free reference demo

The demo uses plain HTML, CSS, and JavaScript so it can be previewed without a package manager, network, or framework assumption. Agents can port the contract to React, Vue, Svelte, or another stack without inheriting a specific component library.
